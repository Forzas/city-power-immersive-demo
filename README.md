# 城市科普项目｜PRD 整体概述

## 1. 项目定位与目标
**一句话概述**
看见城市如何运转——通过互动体验理解每天习以为常、却很少真正看见的城市系统。

**目标**
- 系列化：每一次输出，可扩展成完整内容系列。
- 沉浸感：直观且具亲和力的交互，助力理解深度内容。
- 效率感：用户可在 30 秒理解概况，3 分钟获取系统级认知。
